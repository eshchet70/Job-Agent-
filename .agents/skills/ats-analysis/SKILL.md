# ATS Analysis
Goal: improve terminology alignment without keyword stuffing or fabrication.

## Procedure
1. Extract role identity, competencies, technical, delivery, leadership, business/domain, tools/methods and qualifications.
2. Classify Critical / Important / Supporting.
3. Check exact match first; semantic equivalent second.
4. Require evidence before recommending a term for insertion.
5. Label each term KEEP, ADD, STRENGTHEN, or DO_NOT_ADD.
6. Return ATS Readiness, Critical Coverage, Important Coverage, Evidence Coverage and gaps.
7. ATS score never overrides Strategic Fit.
