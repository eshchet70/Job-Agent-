# Outreach Drafting
Goal: create recipient-specific messages, not generic mass outreach.

## Recipient objectives
- Hiring manager: connect the role's problem to strongest relevant evidence.
- Recruiter: confirm application + 2–3 strongest requirement matches.
- HM manager/functional leader: broader portfolio/transformation relevance; use selectively.
- Functional peer: perspective/routing request.
- Warm connector: explicit introduction request with forwardable rationale.
- Internal advocate: explain unusual alignment and ask for credible routing/referral.

## Guardrails
- Use only approved evidence IDs.
- Do not invent metrics, relationships, credentials, tools or contact details.
- Draft only. User approval is required before sending.
