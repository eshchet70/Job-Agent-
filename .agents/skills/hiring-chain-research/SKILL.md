# Hiring Chain Research
Goal: identify credible human access paths for Tier 1 and strong Tier 2 roles.

## Order
1. Hiring manager
2. Recruiter / talent partner
3. Warm connector
4. Hiring manager's manager
5. Functional leader / peer
6. Internal advocate

## Requirements
- Store current title, company, relationship to vacancy, source, checked date, connection path and priority.
- Confidence: Confirmed / High / Medium / Low.
- Never state an inferred person is confirmed.
- Never invent emails, reporting lines or mutual connections.
- Prefer current official/public evidence; authenticated context may enrich but must be labeled by provenance.
